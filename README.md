# Economic Indicators Pipeline

A reproducible data pipeline for collecting, processing, analyzing, and visualizing U.S. economic indicators.

## Initial Indicators

- Unemployment rate
- Consumer Price Index (CPI)
- Industrial production

## Project Goals

- Collect economic data from public sources
- Standardize data from multiple indicators
- Create a scalable pipeline that can support additional data sources
- Analyze changes and trends in economic conditions
- Visualize economic indicators in an interactive dashboard
- Make the project reproducible with Docker
